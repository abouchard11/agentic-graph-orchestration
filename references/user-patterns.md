# Patterns from the author's working repos

- Adversarial multi-agent roles with source-of-truth controls.
- Injectable eval harnesses when there is no single reference output.
- Fail-closed safety (majority vote, refusal vs noise).
- Reliability as infrastructure (fallback chains, time budgets, denial-of-wallet).
- Skill suites with narrow triggers.
- Case-study reproducibility: invariants, machine-checkable bounds, explicit assumptions.

When the graph touches character systems, content safety, or multi-turn evaluation, default to these patterns.
