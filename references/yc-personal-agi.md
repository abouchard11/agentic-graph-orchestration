# YC / Garry Tan Personal AGI practices (mid-2026)

- Personal AGI: agents on your infrastructure that compound your knowledge.
- Smaller teams than ever: one person plus agents.
- Markdown is code. A well-written skill file is an employee.
- Skill-maxxing: turn every recurring procedure into a versioned, loadable skill.
- GStack / GBrain: personal coding harness + memory over markdown.

When building agent systems, default to producing reusable SKILL.md files or graph definitions that can be checked into the repo.
